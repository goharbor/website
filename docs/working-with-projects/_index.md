This section describes how users manage and participate in Harbor projects according to their assigned built-in or custom project roles. The Harbor system administrator can also perform all of these tasks.

Starting with Harbor v2.16.0, system administrators can define custom project roles. The permissions selected for a custom role determine which operations its members can perform in a project. For details, see [User Permissions By Role](../administration/managing-users/user-permissions-by-role.md) and [Assign Users to a Project](create-projects/add-users.md).
